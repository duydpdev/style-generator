Schema notes (artifact-type/reference/format.md of that version)
- Top level: `name` and `version` are kept silently; `meta` is free-form author data.
  None is required by the page. Every family except `type` is `{ tokens: [{ name, value, usage? }] }`.
- color: `themes` = [{ id, name }] (<= 8; first theme = the base, ids lowercased);
  `tokens` = one flat list; `value` = a string (first theme) or { <theme id>: value }.
  Values: hex (lowercased), rgb/rgba/hsl/hsla/oklch/oklab/lab/lch/color() with plain
  numbers, or an alias "{other-token}". No var(), url(), color-mix(), named colours:
  such a value drops.
- type: { fonts: [], families: { <key>: <stack> }, groups: [{ name, family, styles }] };
  a style = { name, fontSize, lineHeight (length or unitless < 10), fontWeight,
  letterSpacing?, family?, sample?, usage? }. Styles have their own name namespace.
- spacing, radius, borderWidth, backdropBlur, opacity, breakpoint: lists of
  { name, value, usage }; plain CSS values, no var()/url().
- shadow: a box-shadow string, or per theme like colours.
- Every family but `type` shares ONE `--<name>` namespace: a duplicate name drops.
- tokens.css (generated by the page): `:root, [data-theme="<first>"]` + one
  `[data-theme="<id>"]` block per further theme, aliases re-declared per block.
