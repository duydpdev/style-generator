# Next.js + Tailwind v4 example

Thin Next.js 16 (App Router, React 19) app over the shared [`design-system`](../design-system/README.md) package. It adds only wiring (`next.config.ts`, the CSS entry) and one framework-specific component, `ThemeSwitch.tsx`. Theme JSON, generator options, tokens, `cn`, the headless recipes and the shared CSS all come from `design-system-example`.

## Prerequisites

`package.json` depends on the library through `"@duydpdev/style-generator": "link:../.."` and on the design system through `"design-system-example": "workspace:*"`, so the library **must be built first**. The example is a Yarn workspace of the repo root, so the root install also installs it. Node >= 22.18 is required (the config imports a `.ts` module from the design system):

```bash
# From the repo root
yarn install
yarn build:all   # lib (dist/) + CLI (dist/cli/index.mjs)
```

## Run the example

```bash
cd examples/next-v4
yarn dev          # Next.js dev server on http://localhost:3000
```

## How theme generation works (no Vite)

Next.js runs on Turbopack/webpack, so the Vite-only `styleGenVite` plugin does not apply. `next.config.ts` wraps the Next config in `styleGenNext` from `@duydpdev/style-generator/next`, which calls the programmatic `generate()` API whenever Next evaluates the config and writes `app/theme/theme.css` (gitignored) from `../design-system/src/theme.json`. The generator options come from `design-system-example/style-gen.options`. `transpilePackages: ["design-system-example"]` lets Next compile the design system's TypeScript source.

`app/globals.css` imports `tailwindcss`, the generated `theme.css`, the design system's `palettes.css` and `style-guide.css`, and adds `@source "../../design-system/src"` so Tailwind scans the recipes.

## Scripts

| Script           | What it does                                                    |
| ---------------- | --------------------------------------------------------------- |
| `yarn dev`       | Next.js dev server (theme.css regenerated on config evaluation) |
| `yarn build`     | Production build (Turbopack, the Next 16 default)               |
| `yarn start`     | Serve the production build                                      |
| `yarn typecheck` | `tsc --noEmit`                                                  |

## Layout (App Router)

```text
examples/next-v4
├── next.config.ts        # styleGenNext + transpilePackages
├── postcss.config.mjs    # @tailwindcss/postcss
├── package.json
├── tsconfig.json
└── app/
    ├── layout.tsx        # <html> + Google Fonts
    ├── page.tsx          # server component composing the design-system recipes
    ├── ThemeSwitch.tsx   # "use client": sets the data-* axis attributes on <html> via axisAttributes
    ├── globals.css       # tailwindcss + theme.css + shared design-system CSS + @source
    └── theme/theme.css   # generated by styleGenNext (gitignored)
```

The multi-axis scope table (which overrides the library generates and which stay hand-written CSS) lives in the [design-system README](../design-system/README.md#theme-axes).
