# Nâng cấp từ 5.x lên 6.0

6.0.0 có hai thay đổi phá vỡ tương thích: entry point gốc `@duydpdev/style-generator` giờ chỉ export generator, và key `plugin` của `style-gen.config.json` đã bị gỡ. CSS được sinh ra và các biến `--sg-*` không đổi: sinh lại `theme.css` sau khi nâng cấp cho ra đúng file cũ.

Các lần nâng cấp trước: xem [`4.x-to-5.0.md`](./4.x-to-5.0.md) và [`3.x-to-4.0.md`](./3.x-to-4.0.md). Toàn bộ quy tắc nằm trong [`README.md`](../README.md).

## Trước khi nâng cấp

**1. Tìm mọi import 13 symbol đã chuyển khỏi root.** Chạy lệnh này từ thư mục gốc repository; mỗi kết quả là một import phải chuyển sang subpath (bảng bên dưới cho biết sang đâu):

```bash
rg -n -U --pcre2 -g '*.{ts,tsx,mts,cts,js,jsx,mjs,cjs,vue,svelte,astro}' \
  'import[^;]*\b(createDesignTokens|createVariantMapper|toKebabCase|resolveSpacing|resolveSpacingProps|Breakpoint|defaultScreens|COLOR_STATES|DEFAULT_BORDER_VALUES|DEFAULT_ROUNDED_VALUES|DEFAULT_SPACING_PROPERTIES|borderProperties|roundedProperties)\b[^;]*from\s*[\x22\x27]@duydpdev/style-generator[\x22\x27]' .
```

Một import đã bị gỡ sẽ làm build lỗi (lỗi TypeScript `has no exported member`, hoặc `does not provide an export named` lúc chạy), nên không có gì hỏng một cách âm thầm.

**2. Kiểm tra `style-gen.config.json` và `package.json["style-gen"]` xem có key `plugin` không.** Key này là tùy chọn từ 5.2.0 và `init` không còn ghi nó từ đó. Nếu bạn vẫn còn, hãy xóa nó cùng với `plugins/theme-plugin.ts` cũ (xem [`plugin` config key removed](#plugin-config-key-removed)).

**3. Ghim đúng phiên bản** (`6.0.0`), đổi import và phiên bản ghim trong cùng một commit, và build trước khi merge.

## Thay đổi phá vỡ tương thích

### Root barrel is generator-only

`@duydpdev/style-generator` giờ export `generate`, `generateThemeCss`, `defineTheme`, `defineOptions`, `formatZodError` và các type. Mọi thứ còn lại vốn đã có sẵn trên một subpath; hãy import từ đó:

| Symbol                                                                                                                                                                             | 5.x                         | 6.0                                 |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------- | ----------------------------------- |
| `createDesignTokens`, `Breakpoint` (giá trị và type), `defaultScreens`, `COLOR_STATES`, `DEFAULT_BORDER_VALUES`, `DEFAULT_ROUNDED_VALUES`, `borderProperties`, `roundedProperties` | `@duydpdev/style-generator` | `@duydpdev/style-generator/tokens`  |
| `createVariantMapper`, `toKebabCase` (cả `COLOR_STATES`)                                                                                                                           | `@duydpdev/style-generator` | `@duydpdev/style-generator/cva`     |
| `resolveSpacing`, `resolveSpacingProps`, `DEFAULT_SPACING_PROPERTIES`                                                                                                              | `@duydpdev/style-generator` | `@duydpdev/style-generator/spacing` |

```ts
// 5.x
import {
  defineTheme,
  generate,
  Breakpoint,
  createVariantMapper,
} from "@duydpdev/style-generator";

// 6.0
import { defineTheme, generate } from "@duydpdev/style-generator";
import { Breakpoint } from "@duydpdev/style-generator/tokens";
import { createVariantMapper } from "@duydpdev/style-generator/cva";
```

Mọi type trừ `Breakpoint` vẫn được export từ `.` và từ `@duydpdev/style-generator/types`. `Breakpoint` vừa là giá trị vừa là type, nên ở cả hai vai trò nó đều đến từ `/tokens`.

Lý do: root từng kéo các helper token có kiểu, CVA và spacing vào mọi consumer chỉ cần `generate()`. Với root hẹp hơn, một build script chỉ import `generate` không còn mang theo chúng nữa, và bundle của root nhỏ đi.

### `plugin` config key removed

`style-gen.config.json` và `package.json["style-gen"]` chấp nhận `$schema`, `theme`, `output` và các option của generator. Key `plugin` giờ bị từ chối như mọi key lạ khác, và `style-gen doctor` không còn in dòng `Script`. `doctor` thoát với mã 1 và in:

```text
  Config  (style-gen.config.json         ) ❌ Invalid
plugin → Unrecognized key: "plugin"
```

Cách sửa: xóa key `plugin` và `plugins/theme-plugin.ts` cũ mà nó trỏ tới, hoặc chạy `style-gen init`, lệnh này bỏ key đó khi gộp phần còn lại của config. Plugin Vite và Next (`styleGenVite`, `styleGenNext`) cùng `style-gen generate` đã tự sinh CSS, nên không cần thay thế.

## Rollback

Ghim `5.4.x` (`yarn add @duydpdev/style-generator@5.4.1`). Cả hai thay đổi chỉ là sửa import và config, nên hoàn tác chúng sẽ trả lại hành vi 5.x; CSS được sinh ra không cần đổi gì.
