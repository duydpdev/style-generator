# Vite + React starter

A minimal Vite + React + Tailwind CSS v4 app wired through
[`@duydpdev/style-generator`](https://duydpdev.github.io/style-generator/).

```bash
npm install
npm run dev
```

Edit `styles/theme.json`: the plugin in `vite.config.ts` rewrites `src/theme.css`
and `src/theme.tokens.ts` (both git-ignored) whenever the theme changes.
Docs: <https://duydpdev.github.io/style-generator/docs/introduction>
